# AI QE Loop (Stages 1–3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a public GitHub repo where Claude Code agents pull pinned context, plan and generate Playwright tests for Jira stories, and CI enforces deterministic checks and role approvals.

**Architecture:** A mock Auth Service (Express + TypeScript) is the system under test. Plain TypeScript scripts implement the Stage 1 context snapshot and the Stage 3 checks (traceability, approvals, assertion guard), each split into pure functions (unit-tested with the Node test runner) and a thin CLI. Playwright's own planner/generator/healer agents are installed unchanged; project rules live in `CLAUDE.md` and five project skills. GitHub Actions runs the checks; branch protection makes them required.

**Tech Stack:** Node 24, TypeScript 5, tsx 4, Express 5, @playwright/test 1.64.0, ajv 8, minimatch 10, ESLint 9 + typescript-eslint 8 + eslint-plugin-playwright 2, Stryker 9 (command runner), GitHub Actions, gh CLI.

**Spec:** `docs/specs/2026-10-10-ai-qe-loop-design.md`

## Global Constraints

- Repo: `lucaram/ai-qe-loop`, **public**, default branch `main`.
- Source folder names are kept as they are: `external/jira-requirement/`, `external/budiness-rule/`, `external/architecture/`, `external/api/`. Paths are set once in `scripts/config.ts`.
- All text files use LF line endings (`.gitattributes`: `* text=auto eol=lf`).
- Locked message, exact text: `Your account is locked. Try again in 15 minutes.`
- Wrong-credentials message, exact text: `Wrong username or password.`
- Lockout: 5 failed attempts in a row → locked for 15 minutes (900 000 ms); locked while `now < lockedUntil`.
- Test hooks exist only when `TEST_HOOKS=1`.
- Approval labels: `approved:<role>`, roles `po`, `architect`, `engineer`, `developer`, `qe`, `ai-qe-lead`; all mapped to user `lucaram` in `roles.json`.
- Agents and skills never add `approved:*` labels and never merge PRs.
- Test tags: `@<STORY-KEY>`, `@AC-<n>`, `@BR-<nnn>`.
- Branch names: `context/<yyyy-mm-dd>`, `<KEY>-plan`, `<KEY>-tests`, `heal/<yyyy-mm-dd>`, `framework/<topic>`.
- Required checks: `typecheck-lint`, `tests`, `traceability`, `flaky`, `assertion-guard`, `mutation`, `approvals`.
- Mutation threshold: `break: 60`.
- Playwright agents generated by `npx playwright init-agents --loop=claude` are committed unchanged.

**Three refinements of the spec, made while planning (tell the user):**
1. *Traceability scope.* A story's ACs, and the BRs its plan references, must be covered only once the story's plan is on the base branch (`origin/main` for PRs, `HEAD^` for pushes to `main`). Otherwise the plan PR itself could never pass. BRs that no plan references are reported as warnings.
2. *Stale approvals.* An approval label only counts if it was added after the PR's latest commit, the same as GitHub's "dismiss stale reviews".
3. *Separate workflow for approvals.* `approvals` runs in its own workflow (`approvals.yml`). If it shared `ci.yml`, label events would re-run the workflow with the other jobs skipped, and a skipped run would hide an earlier failure.

## Review Focus

1. **Line endings:** a source file with CRLF line endings must hash the same as the LF version. Otherwise `manifest.json` changes on every Windows pull. Pinned in Task 4.
2. **Label added then removed:** a removed `approved:po` label must not count, even though a `labeled` event exists in the history. Pinned in Task 7.
3. **Label re-added by the right person:** if a non-PO adds `approved:po`, then the PO removes it and adds it again, the approval counts. The latest `labeled` actor wins. Pinned in Task 7.
4. **Lock ends exactly on time:** when `now === lockedUntil`, login is allowed and the count is back to 0. When `now === lockedUntil - 1`, it is still refused. Pinned in Task 2.
5. **Typo in a tag:** a test tagged `@BR-01` or `@AC-9` for a story without AC-9 must fail traceability, not pass silently. Pinned in Task 6.

```ts
import { randomUUID } from 'node:crypto';

export const MAX_FAILED_ATTEMPTS = 5;
export const LOCK_DURATION_MS = 15 * 60 * 1000;
export const LOCKED_MESSAGE = 'Your account is locked. Try again in 15 minutes.';
export const WRONG_CREDENTIALS_MESSAGE = 'Wrong username or password.';

export interface Account {
  password: string;
  failedAttempts: number;
  lockedUntil: number | null;
}

export type AccountStore = Map<string, Account>;

export type LoginResult =
  | { status: 200; body: { token: string } }
  | { status: 401 | 423; body: { message: string } };

const wrongCredentials = (): LoginResult => ({ status: 401, body: { message: WRONG_CREDENTIALS_MESSAGE } });
const locked = (): LoginResult => ({ status: 423, body: { message: LOCKED_MESSAGE } });

// State as the outside world sees it: a lock that has ended counts as no lock and 0 attempts.
export function effectiveState(account: Account, now: number) {
  if (account.lockedUntil !== null && now >= account.lockedUntil) {
    return { failedAttempts: 0, lockedUntil: null, locked: false };
  }
  return {
    failedAttempts: account.failedAttempts,
    lockedUntil: account.lockedUntil,
    locked: account.lockedUntil !== null,
  };
}

export function attemptLogin(store: AccountStore, username: string, password: string, now: number): LoginResult {
  const account = store.get(username);
  if (!account) return wrongCredentials();

  if (account.lockedUntil !== null) {
    if (now < account.lockedUntil) return locked();
    account.lockedUntil = null;
    account.failedAttempts = 0;
  }

  if (password === account.password) {
    account.failedAttempts = 0;
    return { status: 200, body: { token: randomUUID() } };
  }

  account.failedAttempts += 1;
  if (account.failedAttempts >= MAX_FAILED_ATTEMPTS) {
    account.lockedUntil = now + LOCK_DURATION_MS;
    return locked();
  }
  return wrongCredentials();
}
```

```ts
import type { Express } from 'express';
import { effectiveState, type Account, type AccountStore } from './auth';

export const DEFAULT_TEST_PASSWORD = 'Correct-Pass-1';

interface AccountSetup {
  password?: string;
  failedAttempts?: number;
  lockedForMs?: number | null;
}

// ADR-0001: tests set up locked accounts by writing the stored fields, instead of waiting 15 minutes.
export function registerTestHooks(app: Express, store: AccountStore, now: () => number): void {
  app.put('/test/accounts/:username', (req, res) => {
    const setup = (req.body ?? {}) as AccountSetup;
    const existing: Account = store.get(req.params.username)
      ?? { password: DEFAULT_TEST_PASSWORD, failedAttempts: 0, lockedUntil: null };
    const account: Account = {
      password: setup.password ?? existing.password,
      failedAttempts: setup.failedAttempts ?? existing.failedAttempts,
      lockedUntil: setup.lockedForMs === undefined
        ? existing.lockedUntil
        : setup.lockedForMs === null ? null : now() + setup.lockedForMs,
    };
    store.set(req.params.username, account);
    res.json(effectiveState(account, now()));
  });

  app.get('/test/accounts/:username', (req, res) => {
    const account = store.get(req.params.username);
    if (!account) {
      res.status(404).json({ message: 'No such account.' });
      return;
    }
    res.json(effectiveState(account, now()));
  });
}
```

```ts
import express from 'express';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { attemptLogin, type AccountStore } from './auth';
import { registerTestHooks } from './test-hooks';

const publicDir = path.join(path.dirname(fileURLToPath(import.meta.url)), '..', 'public');

export function createApp(store: AccountStore, options: { testHooks: boolean; now?: () => number }) {
  const now = options.now ?? Date.now;
  const app = express();
  app.use(express.json());

  app.get('/health', (_req, res) => {
    res.json({ ok: true });
  });

  // ADR-0002: the Auth Service decides the lock; the UI only shows the message.
  app.post('/auth/login', (req, res) => {
    const { username, password } = req.body ?? {};
    if (typeof username !== 'string' || typeof password !== 'string') {
      res.status(400).json({ message: 'Username and password are required.' });
      return;
    }
    const result = attemptLogin(store, username, password, now());
    res.status(result.status).json(result.body);
  });

  if (options.testHooks) registerTestHooks(app, store, now);

  app.use(express.static(publicDir));
  return app;
}
```

```ts
import { createHash } from 'node:crypto';
import { existsSync, mkdirSync, readdirSync, readFileSync, rmSync, writeFileSync } from 'node:fs';
import path from 'node:path';
import { CONTEXT_DIR, SOURCE_DIR } from './config';
import { isMain } from './cli';

export interface ManifestEntry { path: string; sha256: string }
export interface Manifest { pulled_at: string; files: ManifestEntry[] }

const MANIFEST = 'manifest.json';
const toLf = (text: string) => text.replace(/\r\n/g, '\n');

export function hashContent(text: string): string {
  return createHash('sha256').update(toLf(text)).digest('hex');
}

export function listFiles(dir: string): string[] {
  const out: string[] = [];
  const walk = (current: string) => {
    for (const entry of readdirSync(current, { withFileTypes: true })) {
      const full = path.join(current, entry.name);
      if (entry.isDirectory()) walk(full);
      else out.push(path.relative(dir, full).split(path.sep).join('/'));
    }
  };
  walk(dir);
  return out.sort();
}

function sameFiles(a: ManifestEntry[], b: ManifestEntry[]): boolean {
  return a.length === b.length && a.every((entry, i) => entry.path === b[i].path && entry.sha256 === b[i].sha256);
}

export function pullContext(sourceDir: string, contextDir: string, now: Date): { changed: boolean; manifest: Manifest } {
  const files = listFiles(sourceDir).map((rel) => ({
    rel,
    text: readFileSync(path.join(sourceDir, rel), 'utf8'),
  }));
  const entries: ManifestEntry[] = files.map(({ rel, text }) => ({ path: rel, sha256: hashContent(text) }));

  const manifestPath = path.join(contextDir, MANIFEST);
  if (existsSync(manifestPath)) {
    const previous = JSON.parse(readFileSync(manifestPath, 'utf8')) as Manifest;
    if (sameFiles(previous.files, entries)) return { changed: false, manifest: previous };
  }

  rmSync(contextDir, { recursive: true, force: true });
  for (const { rel, text } of files) {
    const target = path.join(contextDir, rel);
    mkdirSync(path.dirname(target), { recursive: true });
    writeFileSync(target, toLf(text));
  }
  const manifest: Manifest = { pulled_at: now.toISOString(), files: entries };
  writeFileSync(manifestPath, JSON.stringify(manifest, null, 2) + '\n');
  return { changed: true, manifest };
}

if (isMain(import.meta.url)) {
  const { changed, manifest } = pullContext(SOURCE_DIR, CONTEXT_DIR, new Date());
  console.log(changed
    ? `Context updated: ${manifest.files.length} files pinned at ${manifest.pulled_at}.`
    : `Context unchanged since ${manifest.pulled_at}.`);
}
```

```ts
import { readFileSync } from 'node:fs';

// The pinned contract from Stage 1 is the source of truth, never the app.
const contract = JSON.parse(readFileSync('context/api/openapi.json', 'utf8'));
const ajv = new Ajv({ strict: false, allErrors: true });
ajv.addSchema(contract, 'openapi');

export function assertMatchesContract(method: string, apiPath: string, status: number, body: unknown): void {
  const responses = contract.paths?.[apiPath]?.[method.toLowerCase()]?.responses;
  if (!responses) throw new Error(`${method} ${apiPath} is not in the API contract.`);

  const response = responses[String(status)];
  if (!response) throw new Error(`${method} ${apiPath} returned ${status}, which the API contract does not document.`);

  const schema = response.content?.['application/json']?.schema;
  if (!schema) return;

  const validate = schema.$ref ? ajv.getSchema(`openapi${schema.$ref}`) : ajv.compile(schema);
  if (!validate) throw new Error(`Cannot resolve schema ${schema.$ref}.`);
  if (!validate(body)) {
    throw new Error(`${method} ${apiPath} ${status} response does not match the API contract: ${ajv.errorsText(validate.errors)}`);
  }
}
```

```ts
import { execFileSync, execSync } from 'node:child_process';
import { appendFileSync, existsSync, readdirSync, readFileSync } from 'node:fs';
import path from 'node:path';
import { BUSINESS_RULE_DIR, CONTEXT_DIR, SPECS_DIR, STORY_DIR } from './config';
import { isMain } from './cli';

export interface Story { key: string; acs: string[] }
export interface TestCase { title: string; file: string; tags: string[] }
export interface TraceInput { stories: Story[]; rules: string[]; plans: { key: string; text: string }[]; tests: TestCase[] }
export interface TraceRow { item: string; tests: string[] }
export interface TraceResult { errors: string[]; warnings: string[]; rows: TraceRow[] }

const STORY_TAG = /^@(?!AC-|BR-)[A-Z][A-Z0-9]*-\d+$/;
const AC_TAG = /^@AC-\d+$/;
const BR_TAG = /^@BR-\d+$/;

export function parseStory(text: string): Story {
  const key = /^Key:\s*(\S+)/m.exec(text)?.[1];
  if (!key) throw new Error('Story file has no "Key:" line.');
  return { key, acs: [...text.matchAll(/^(AC-\d+):/gm)].map((m) => m[1]) };
}

export function parseRuleId(text: string): string | null {
  return /^##\s*(BR-\d+):/m.exec(text)?.[1] ?? null;
}

export function collectTests(listJson: unknown): TestCase[] {
  const out: TestCase[] = [];
  const walk = (suite: { specs?: { title: string; file: string; tags?: string[] }[]; suites?: unknown[] }) => {
    for (const spec of suite.specs ?? []) {
      out.push({
        title: spec.title,
        file: spec.file,
        tags: (spec.tags ?? []).map((t) => (t.startsWith('@') ? t : `@${t}`)),
      });
    }
    for (const child of suite.suites ?? []) walk(child as Parameters<typeof walk>[0]);
  };
  walk(listJson as Parameters<typeof walk>[0]);
  return out;
}

export function evaluate({ stories, rules, plans, tests }: TraceInput): TraceResult {
  const errors: string[] = [];
  const warnings: string[] = [];
  const rows: TraceRow[] = [];
  const storyByKey = new Map(stories.map((s) => [s.key, s]));

  // 1. Every tag must point at something that exists.
  for (const t of tests) {
    const storyTags = t.tags.filter((tag) => STORY_TAG.test(tag));
    for (const tag of storyTags) {
      if (!storyByKey.has(tag.slice(1))) errors.push(`Test "${t.title}" has unknown tag ${tag}.`);
    }
    for (const tag of t.tags.filter((x) => BR_TAG.test(x))) {
      if (!rules.includes(tag.slice(1))) errors.push(`Test "${t.title}" has unknown tag ${tag}.`);
    }
    const knownStories = storyTags.map((tag) => storyByKey.get(tag.slice(1))).filter((s): s is Story => !!s);
    for (const tag of t.tags.filter((x) => AC_TAG.test(x))) {
      if (storyTags.length === 0) errors.push(`Test "${t.title}" has tag ${tag} but no story tag.`);
      else if (knownStories.length > 0 && !knownStories.some((s) => s.acs.includes(tag.slice(1)))) {
        errors.push(`Test "${t.title}" has tag ${tag}, but ${knownStories.map((s) => s.key).join('/')} has no ${tag.slice(1)}.`);
      }
    }
  }

  // 2. Stories with an approved plan: every AC and every referenced BR needs a test.
  const plannedRules = new Set<string>();
  for (const planItem of plans) {
    const story = storyByKey.get(planItem.key);
    if (!story) {
      errors.push(`Plan for ${planItem.key} has no matching story in context.`);
      continue;
    }
    for (const m of planItem.text.matchAll(/\[(BR-\d+)\]/g)) plannedRules.add(m[1]);
    for (const ac of story.acs) {
      const covering = tests.filter((t) => t.tags.includes(`@${story.key}`) && t.tags.includes(`@${ac}`));
      rows.push({ item: `${story.key} ${ac}`, tests: covering.map((t) => t.title) });
      if (covering.length === 0) errors.push(`${story.key} ${ac} has no test.`);
    }
  }
  for (const rule of rules) {
    const covering = tests.filter((t) => t.tags.includes(`@${rule}`));
    if (plannedRules.has(rule)) {
      rows.push({ item: rule, tests: covering.map((t) => t.title) });
      if (covering.length === 0) errors.push(`${rule} has no test.`);
    } else {
      warnings.push(`${rule} is not referenced by any approved plan.`);
    }
  }
  return { errors, warnings, rows };
}

export function renderMarkdown({ errors, warnings, rows }: TraceResult): string {
  const lines = ['## Traceability matrix', '', '| Item | Tests |', '|---|---|'];
  for (const row of rows) lines.push(`| ${row.item} | ${row.tests.length ? row.tests.join('<br>') : '**none**'} |`);
  if (errors.length) lines.push('', '### Errors', ...errors.map((e) => `- ${e}`));
  if (warnings.length) lines.push('', '### Warnings', ...warnings.map((w) => `- ${w}`));
  return lines.join('\n') + '\n';
}

function readDir(dir: string): string[] {
  return existsSync(dir) ? readdirSync(dir).map((f) => readFileSync(path.join(dir, f), 'utf8')) : [];
}

if (isMain(import.meta.url)) {
  const baseIndex = process.argv.indexOf('--base');
  const base = baseIndex > -1 ? process.argv[baseIndex + 1] : 'HEAD';

  const stories = readDir(path.join(CONTEXT_DIR, STORY_DIR)).map(parseStory);
  const rules = readDir(path.join(CONTEXT_DIR, BUSINESS_RULE_DIR)).map(parseRuleId).filter((r): r is string => !!r);

  // A plan counts as approved once it is on the base branch (merged after PO approval).
  const approvedPlanFiles = execFileSync('git', ['ls-tree', '-r', '--name-only', base, `${SPECS_DIR}/`], { encoding: 'utf8' })
    .split('\n')
    .filter((f) => /^specs\/[A-Z][A-Z0-9]*-\d+-.+\.md$/.test(f));
  const plans = approvedPlanFiles
    .filter((f) => existsSync(f))
    .map((f) => ({ key: /^specs\/([A-Z][A-Z0-9]*-\d+)-/.exec(f)![1], text: readFileSync(f, 'utf8') }));
```

```ts
import { execFileSync } from 'node:child_process';
import { appendFileSync, readFileSync } from 'node:fs';
import { minimatch } from 'minimatch';
import { isMain } from './cli';

export interface RoleConfig { users: string[]; approves: string[] }
export type Roles = Record<string, RoleConfig>;
export interface LabelEvent { event: string; created_at: string; label?: { name: string }; actor?: { login: string } | null }
export interface ApprovalStatus { role: string; label: string; present: boolean; addedBy: string | null; reason: string | null }

export function requiredRoles(roles: Roles, changedFiles: string[]): string[] {
  return Object.entries(roles)
    .filter(([, config]) => changedFiles.some((file) => config.approves.some((glob) => minimatch(file, glob, { dot: true }))))
    .map(([role]) => role);
}

export function evaluateApprovals(input: {
  roles: Roles; changedFiles: string[]; currentLabels: string[]; events: LabelEvent[]; headCommittedAt: string;
}): { ok: boolean; statuses: ApprovalStatus[] } {
  const statuses = requiredRoles(input.roles, input.changedFiles).map((role): ApprovalStatus => {
    const label = `approved:${role}`;
    const present = input.currentLabels.includes(label);
    const lastAdd = input.events.filter((e) => e.event === 'labeled' && e.label?.name === label).at(-1);
    const addedBy = lastAdd?.actor?.login ?? null;

    let reason: string | null = null;
    if (!present) reason = `Label ${label} is missing.`;
    else if (!addedBy || !input.roles[role].users.includes(addedBy)) {
      reason = `${label} was added by ${addedBy ?? 'unknown'}, who is not listed for role ${role}.`;
    } else if (new Date(lastAdd!.created_at) < new Date(input.headCommittedAt)) {
      reason = `${label} was added before the latest commit. Remove it and add it again after reviewing the new changes.`;
    }
    return { role, label, present, addedBy, reason };
  });
  return { ok: statuses.every((s) => s.reason === null), statuses };
}

export function renderSummary(statuses: ApprovalStatus[]): string {
  if (statuses.length === 0) return '## Approvals\n\nNo changed file needs a role approval.\n';
  const lines = ['## Approvals', '', '| Role | Label | Added by | Result |', '|---|---|---|---|'];
  for (const s of statuses) lines.push(`| ${s.role} | \`${s.label}\` | ${s.addedBy ?? '–'} | ${s.reason ?? 'Verified'} |`);
  return lines.join('\n') + '\n';
}

const gh = (...args: string[]) => execFileSync('gh', args, { encoding: 'utf8', maxBuffer: 64 * 1024 * 1024 });

  const repo = process.env.GITHUB_REPOSITORY!;
  const pr = process.env.PR_NUMBER!;
  const roles = JSON.parse(readFileSync('roles.json', 'utf8')) as Roles;

  const changedFiles = gh('pr', 'diff', pr, '--repo', repo, '--name-only').split('\n').filter(Boolean);
  const currentLabels = gh('pr', 'view', pr, '--repo', repo, '--json', 'labels', '--jq', '.labels[].name').split('\n').filter(Boolean);
  const headCommittedAt = gh('pr', 'view', pr, '--repo', repo, '--json', 'commits', '--jq', '.commits[-1].committedDate').trim();
  const events = gh('api', `repos/${repo}/issues/${pr}/events`, '--paginate', '--jq', '.[]')
    .split('\n').filter(Boolean).map((line) => JSON.parse(line) as LabelEvent);

  const result = evaluateApprovals({ roles, changedFiles, currentLabels, events, headCommittedAt });
  const summary = renderSummary(result.statuses);

  if (process.env.GITHUB_STEP_SUMMARY) appendFileSync(process.env.GITHUB_STEP_SUMMARY, summary);
```

```ts
import { execFileSync } from 'node:child_process';
import { appendFileSync } from 'node:fs';
import { isMain } from './cli';

export interface Violation { file: string; line: string }

// The healer may fix locators, waits and navigation. It must not touch what a test checks.
const FORBIDDEN = [/expect\(/, /\.skip\(/, /\.fixme\(/, /\.only\(/, /\btag\s*:/];

export function findViolations(diff: string): Violation[] {
  const violations: Violation[] = [];
  let file = '';
  for (const line of diff.split('\n')) {
    if (line.startsWith('+++ ')) {
      file = line.replace(/^\+\+\+ (b\/)?/, '');
      continue;
    }
    if (line.startsWith('--- ')) continue;
    if ((line.startsWith('+') || line.startsWith('-')) && FORBIDDEN.some((re) => re.test(line))) {
      violations.push({ file, line });
    }
  }
  return violations;
}

if (isMain(import.meta.url)) {
  const baseIndex = process.argv.indexOf('--base');
  const base = baseIndex > -1 ? process.argv[baseIndex + 1] : 'main';
  const diff = execFileSync('git', ['diff', `${base}...HEAD`, '--', 'tests/'], { encoding: 'utf8' });
  const violations = findViolations(diff);

  const report = violations.length
    ? ['## Assertion guard: failed', '', 'Healer PRs may not change assertions, tags or skips:', '',
       ...violations.map((v) => `- \`${v.file}\`: \`${v.line.trim()}\``)].join('\n')
    : '## Assertion guard: passed\n\nNo assertion, tag or skip changes.';
  console.log(report);
  if (process.env.GITHUB_STEP_SUMMARY) appendFileSync(process.env.GITHUB_STEP_SUMMARY, report + '\n');
  process.exit(violations.length ? 1 : 0);
}
```

````markdown
# Generate tests

Input: a story key, e.g. `PROJ-130` ($ARGUMENTS).

## 1. Prepare

1. `git switch main && git pull --ff-only`
2. Stop unless `git ls-tree --name-only main specs/` lists `specs/<KEY>-*.md`. A plan counts as approved only once it is merged. Tell the user to run `/plan-story <KEY>` and get `approved:po` first.
3. `git switch -c <KEY>-tests`
4. Read the plan and `CLAUDE.md` (conventions and tags).

## 2. API scenarios: write them directly

For each scenario in "API scenarios", write a test in `tests/api/<KEY>-<slug>.spec.ts`:

```ts
import { test, expect } from '@playwright/test';
import { DEFAULT_PASSWORD, getAccount, login, setAccount, uniqueUsername } from '../support/api';

test('<scenario title>', { tag: ['@<KEY>', '@AC-n', '@BR-nnn'] }, async ({ request }, testInfo) => {
  const user = uniqueUsername(testInfo);
  await setAccount(request, user, { failedAttempts: 4 });

  const result = await login(request, user, 'wrong-password');

  expect(result.status).toBe(423);
  expect(result.body.message).toBe('Your account is locked. Try again in 15 minutes.');
});
```

Rules:
- Tags exactly as the scenario heading's IDs.
- Expected values come from the plan (which came from the context), never from what the app returns.
- Use `lockedForMs` for time: e.g. `lockedForMs: 60_000` for "one minute left", `lockedForMs: 0` for "lock ends now".
- Check state changes with `getAccount()` when the plan says a count or lock must (or must not) change.

## 3. UI scenarios: use the generator

For each scenario in "UI scenarios", use the `playwright-test-generator` agent with `tests/seed.spec.ts` as the seed, one scenario at a time. Brief it with the scenario text plus:
> Save to `tests/ui/<KEY>-<slug>.spec.ts`. Add `{ tag: [...] }` with the scenario's IDs. Set up the account through the API first with `setAccount()` from `tests/support/api.ts` and `uniqueUsername(testInfo)`. Use role- or label-based locators. Assert the exact message text from the scenario.

## 4. Verify

Run, and fix the **test code** until they pass:
```bash
npm run typecheck && npm run lint && npm test && npm run traceability
```
(`npm run traceability` uses `HEAD` as base here, so the plan is in scope.)

If a test fails because the app does not do what the plan says, do **not** change the expected value. Leave the test failing, and list it in the PR body under "Possible bugs" with the failure output.

## 5. Open the PR

```bash
git add tests
git commit -m "<KEY>: automated tests"
git push -u origin HEAD
gh pr create --title "<KEY>: automated tests" --body "<body>"
```
Body:
- **Plan:** `specs/<KEY>-<slug>.md`
- **Tests:** a table of scenario → test file and title → tags
- **Possible bugs:** failing tests where the app disagrees with the plan, or "None"
- **Approvals needed:** `- [ ] approved:qe`

Do not add labels and do not merge.
````

### Task 11: CI workflows

**Files:**
- Create: `.github/workflows/ci.yml`, `.github/workflows/approvals.yml`

**Interfaces:**
- Consumes: npm scripts from Tasks 1–9.

- [ ] **Step 1: Write `.github/workflows/ci.yml`**

```yaml
name: ci

on:
  pull_request:
  push:
    branches: [main]

permissions:
  contents: read

concurrency:
  group: ci-${{ github.ref }}
  cancel-in-progress: true

jobs:
  typecheck-lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 24, cache: npm }
      - run: npm ci
      - run: npm run typecheck
      - run: npm run lint
      - run: npm run test:unit

  tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 24, cache: npm }
      - run: npm ci
      - run: npx playwright install --with-deps chromium
      - run: npm test
      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: playwright-report
          path: playwright-report
          retention-days: 14

  traceability:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }
      - uses: actions/setup-node@v4
        with: { node-version: 24, cache: npm }
      - run: npm ci
      - name: Check traceability
        env:
          # PRs: plans already on the target branch are approved. Pushes: plans before this merge.
          BASE: ${{ github.event_name == 'pull_request' && format('origin/{0}', github.base_ref) || 'HEAD^' }}
        run: npm run traceability -- --base "$BASE"

  flaky:
    if: github.event_name == 'pull_request'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }
      - uses: actions/setup-node@v4
        with: { node-version: 24, cache: npm }
      - run: npm ci
      - run: npx playwright install --with-deps chromium
      - name: Repeat new or changed tests 5 times
        run: |
          files=$(git diff --name-only --diff-filter=AM "origin/${{ github.base_ref }}...HEAD" -- 'tests/**/*.spec.ts')
          if [ -z "$files" ]; then echo "No new or changed tests."; exit 0; fi
          echo "$files"
          npx playwright test $files --repeat-each=5

  assertion-guard:
    if: github.event_name == 'pull_request' && startsWith(github.head_ref, 'heal/')
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }
      - uses: actions/setup-node@v4
        with: { node-version: 24, cache: npm }
      - run: npm ci
      - run: npm run assertion-guard -- --base "origin/${{ github.base_ref }}"

  mutation:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 24, cache: npm }
      - run: npm ci
      - run: npx playwright install --with-deps chromium
      - name: Run Stryker
        run: |
          if ! ls tests/api/*.spec.ts >/dev/null 2>&1; then echo "No API tests yet; nothing to measure."; exit 0; fi
          npm run mutation
      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: mutation-report
          path: reports/mutation
          if-no-files-found: ignore
```
